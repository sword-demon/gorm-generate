# 02: 首条生成路径（MySQL 模型 → 预览 → 复制）

**What to build:** 用户粘贴一段 MySQL DDL 后点击生成，右侧出现按表拆分的模型文件列表；点开文件能看到只读的纯文本代码预览；支持复制当前文件与复制全部。生成由 Rust 核心库的纯函数完成，Tauri 命令只是薄包装。解析错误时给出提示而不崩溃。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 粘贴含一张或多张表的 MySQL DDL 能生成对应的模型文件
- [ ] 模型包含结构体、`TableName()` 与基础 GORM/JSON tag
- [ ] 文件列表按表展示，预览显示完整文件内容
- [ ] 单文件复制与全部复制可用
- [ ] 解析失败时界面显示错误提示，应用不崩溃
- [ ] 存在一份 golden 测试锁死该样例 DDL 的完整生成产物
